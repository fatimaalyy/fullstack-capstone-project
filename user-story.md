# User Story Template

**Title:**
As a [type of user], I want [an action] so that [a benefit/value].

**Description:**
A short paragraph explaining the context of the user story, why it matters, and what problem it solves for the user.

**Acceptance Criteria:**
1. [Condition 1 that must be true for the story to be considered done]
2. [Condition 2]
3. [Condition 3]

**Priority:** High / Medium / Low

**Story Points:** [Estimate, e.g. 1, 2, 3, 5, 8]

**Labels:** new / icebox / backlog / technical debt

---

## Example

**Title:**
As a shopper, I want to search for gifts by category so that I can quickly find relevant products.

**Description:**
Users visiting the gift store want a fast way to narrow down products instead of scrolling through the entire catalog. Adding category-based search improves usability and increases the chance of a purchase.

**Acceptance Criteria:**
1. User can enter a search term and select a category filter.
2. Results update to show only items matching the category.
3. If no items match, a "no results found" message is displayed.

**Priority:** High

**Story Points:** 3

**Labels:** new
